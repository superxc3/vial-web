This is a customised build of Vial for XCMKB keyboards. It is not affiliated with or supported by the Vial project; the official web version is at vial.rocks. Please report issues with this build to XCMKB.
Requires Chrome, Chromium or Edge (WebHID). Source code: vial-web · vial-gui (GNU GPL v2 or later) · Firmware changelog

In order to proceed, the keyboard must be set into unlocked mode. You should only perform this operation on computers that you trust.

To exit this mode, you will need to replug the keyboard or select Security->Lock from the menu.
